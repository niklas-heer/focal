# Milestone 3 — Chrome Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Focal gets its chrome: a bottom formatting bar that appears when the pointer nears the bottom edge, a focus mode that dims all but the current sentence or paragraph with typewriter scrolling, folder mode (`focal .`) with a sidebar and a ⌘P quick switcher, a small settings window, and a native menu bar.

**Architecture:** A new `Workspace` view becomes the window's root. It owns the current `Editor` entity, the optional folder (file list, watcher, sidebar), the bottom bar and the quick switcher, and swaps editors when another file opens. The editor keeps text, caret and rendering; the formatting bar dispatches the same actions as the keyboard and menus, so all three share one code path. The Markdown edits behind the bar (headings, list and quote prefixes, links, blocks), the word count, sentence ranges and fuzzy matching are pure functions in `focal-core`. Settings are a GPUI global loaded from and saved to a JSON file.

**Tech Stack:** Rust 1.97.1, `gpui-kit` 0.7.0 (`Input`, `Switch`, `Radio`, `Kbd`, `NativeMenu`, GPUI animation), `notify` 7 (recursive folder watch), `serde` + `serde_json` (settings), `unicode-segmentation` (words and sentences), GPUI Kit's headless test harness.

**Spec:** [`docs/design.md`](../../design.md), section 3 (command line, folder mode), section 6 (bottom bar, focus mode, settings) and section 1 (principles).

## Global Constraints

- The file is the document: opening, switching files and saving never change bytes that were not edited.
- Bottom bar (design 6): at the bottom edge; fades in when the pointer comes within about 40 pt of the bottom, fades out shortly after the pointer leaves; never appears while typing; holds the file name, heading level, bold, italic, strikethrough, inline code, link, lists, task, quote, table, code block, math and a focus toggle; word count and reading time on its trailing side.
- Focus mode (design 6): off by default, ⌘D toggles it; dims everything except the current sentence or paragraph (a setting); typewriter scrolling keeps the current line vertically centered (a setting); hides the sidebar and the bar.
- Folder mode (design 3): `focal .` or `focal ~/notes` opens the folder; one window with a sidebar of Markdown files, collapsed by default and toggled with a shortcut; the list updates live; ⌘P opens a fuzzy quick switcher by file name; switching files saves the current one first.
- Settings (design 6, kept small): focus unit and typewriter scrolling in this milestone. Prose font, text size and column width need the fixed text size to become a setting and move to a later milestone (the updates setting arrives with M6).
- `mise run check` passes after every task; logic lives in `focal-core` with unit tests; UI behavior has headless UI tests; no `unsafe` code.
- Work on branch `m3-chrome` in `.worktrees/rust-gpui`; conventional commits with the session's `Co-Authored-By` line; `mise run clean` when done.

## Review Focus

1. **Switching files while a table cell or IME composition is open**: the typed text is saved into the file it belongs to, never into the next file. Task 6 tests switching with an open cell.
2. **A folder with no Markdown files, or thousands of them**: `focal empty/` opens a new `Untitled.md` in that folder (created on first save), and scanning stops at a cap instead of freezing. Task 6 tests the empty folder and the cap.
3. **Formatting at the edges**: heading or list toggles on the last line without a trailing newline, on an empty document, and on a multi-line selection that spans a list and plain text. Task 1 tests these.
4. **Typing while the pointer rests at the bottom edge**: the bar hides on the first keystroke and stays hidden until the pointer moves. Task 4 tests it.
5. **Focus mode with the caret in a table or code block**: the dimming follows the block, and typewriter scrolling does not jump while a cell is edited. Task 5 tests the table case.

### Task 1: Formatting edits in `focal-core`

**Files:**
- Modify: `crates/focal-core/src/editing.rs`

**Interfaces:**
- Consumes: `Analysis` (lines, `info(line).prefix`, `LineKind::Heading(level)`), `LineIndex`, `Change { range, text, selection }`, `toggle_wrap`.
- Produces:
  - `pub fn set_heading(analysis: &Analysis, text: &str, line: usize, level: u8) -> Change` — level 0 removes the heading; replaces an existing `#…# ` run; keeps the caret on the same text.
  - `pub enum BlockPrefix { Bullet, Numbered, Task, Quote }` and `pub fn toggle_prefix(analysis: &Analysis, text: &str, selection: &Range<usize>, prefix: BlockPrefix) -> Change` — applies to every line the selection touches: removes the prefix when all those lines already have it, otherwise adds it (numbered lists count up from 1; a task turns a bullet into `- [ ] `).
  - `pub fn insert_link(text: &str, selection: &Range<usize>) -> Change` — `[selection]()` with the caret between the parentheses; with an empty selection, `[]()` with the caret between the brackets.
  - `pub fn insert_block(text: &str, selection: &Range<usize>, block: Block) -> Change` with `pub enum Block { Table, CodeBlock, Math }` — a table template (`| Column | Column |\n| --- | --- |\n|  |  |`), or fences (```` ``` ```` or `$$`) around the selected lines; the block starts on its own paragraph.

### Task 2: Text statistics, sentences and fuzzy matching in `focal-core`

**Files:**
- Create: `crates/focal-core/src/text_stats.rs`, `crates/focal-core/src/fuzzy.rs`
- Modify: `crates/focal-core/src/lib.rs`

**Interfaces:**
- Produces:
  - `pub fn word_count(text: &str) -> usize` (Unicode words; Markdown markers are not words) and `pub fn reading_minutes(words: usize) -> usize` (230 words per minute, at least 1 for a non-empty text).
  - `pub fn sentence_at(text: &str, range: Range<usize>, offset: usize) -> Range<usize>` — the Unicode sentence inside `range` (a paragraph) containing `offset`, trimmed of trailing whitespace.
  - `pub fn fuzzy_score(query: &str, candidate: &str) -> Option<i64>` — case-insensitive subsequence match; higher is better; bonuses for matches at word starts (after `/`, `-`, `_`, space, `.`), consecutive runs and the file name part; `None` when not a subsequence. `pub fn fuzzy_rank<'a>(query: &str, candidates: impl IntoIterator<Item = &'a str>) -> Vec<(usize, i64)>` sorted by score, then shorter candidate.
