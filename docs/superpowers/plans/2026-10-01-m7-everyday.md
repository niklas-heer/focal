# Milestone 7 — Everyday Editing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The everyday commands a Mac editor is expected to have: Find and Replace, New, Open… (a file or a folder) and Open Recent, without losing untitled text.

**Architecture:** Matching lives in `focal-core` (`find.rs`) as pure functions over the text. The editor keeps the current query and its matches, recomputed with every edit, and paints them under the text the way it paints the selection; the current match is the selection. A small find bar (`find_bar.rs`, two GPUI Kit inputs) floats at the top of the workspace and drives the editor. New and Open are app-level actions that go through `windows::open`, like `focal` requests; Open… uses the system open panel (`cx.prompt_for_paths`). Recent files are a JSON list beside the settings, shown as File ▸ Open Recent and handed to macOS for the Dock menu.

**Tech Stack:** Rust, GPUI (`prompt_for_paths`, `add_recent_document`, `MenuItem::submenu`, `on_window_should_close`), GPUI Kit inputs, `NSAlert` through `objc2-app-kit`.

**Spec:** [`docs/design.md`](../../design.md) section 3 (opening files and folders), section 6 (settings files), section 8 (milestones; M7 added by this plan).

## Global Constraints

- The file is the document: finding never changes the text; replacing is an ordinary edit with one undo step per command ("Replace All" is one step).
- Matching ignores case and finds non-overlapping matches, scanning forward; offsets are byte offsets on character boundaries.
- Shortcuts follow macOS: ⌘F Find, ⌥⌘F Find and Replace, ⌘G Find Next, ⇧⌘G Find Previous, ⌘N New, ⌘O Open…, Escape closes the find bar.
- No text is lost: closing a window whose untitled document has unsaved edits asks first (Save…, Don't Save, Cancel); quitting with such windows asks too.
- Alerts run outside GPUI updates (spawned), as `mac::alert` already requires.
- `mise run check` passes after every task; logic in `focal-core` with unit tests; UI behavior with headless UI tests.
- Work on branch `m7-everyday` in `.worktrees/rust-gpui`; conventional commits with the session's `Co-Authored-By` line; `mise run clean` when done.

## Review Focus

1. **A query whose lowercase form has a different byte length (`İ`, `ß`), or that spans a line break**: matches stay on character boundaries and never panic. Task 1 tests non-ASCII text and a multi-line query.
2. **Editing while the find bar is open**: matches follow the text (an edit inside a match removes it; new matches appear), and the count stays right. Task 2 tests typing after a search.
3. **Replace when the selection is not a match** (the caret moved away): Replace first moves to the next match instead of replacing the selection. Task 2 tests it.
4. **A recent file that was deleted or moved**: it is left out of the menu, and choosing a stale entry shows nothing broken. Task 4 tests a missing file.
5. **Open… choosing a file that is already open**: its window comes forward instead of a second window (as for `focal`). Task 3 relies on `windows::open`, which already does this; its test opens the same path twice.

### Task 1: Matching in focal-core

**Files:** Create `crates/focal-core/src/find.rs`; modify `crates/focal-core/src/lib.rs`.

**Produces:**
- `pub fn find_all(text: &str, query: &str) -> Vec<Range<usize>>` — case-insensitive (per character, `char::to_lowercase`), non-overlapping, in order; empty query → empty.
- `pub fn next_match(matches: &[Range<usize>], from: usize) -> Option<usize>` — index of the first match starting at or after `from`, wrapping to 0.
- `pub fn previous_match(matches: &[Range<usize>], before: usize) -> Option<usize>` — index of the last match starting before `before`, wrapping to the last.
- `pub fn replace_all(matches: &[Range<usize>], text: &str, replacement: &str) -> Option<editing::Change>` — one change spanning the first to the last match, with the selection after the last replacement.

- [ ] Tests first: ASCII and mixed case; `Straße`/`STRASSE` does not match (no full folding) but `ÄÖ`/`äö` does; matches never split a character; a query with `\n`; overlapping (`aa` in `aaa` → one); next/previous wrap; replace_all keeps text between matches.
- [ ] Implement; `cargo test -p focal-core find`; commit `feat(core): case-insensitive find and replace-all`.

### Task 2: The editor finds, highlights and replaces

**Files:** Modify `crates/focal/src/editor.rs`, `crates/focal/src/theme.rs` (`found` color); test in `crates/focal/src/ui_tests.rs`.

**Consumes:** Task 1. **Produces:** `Editor::set_query(&mut self, query: Option<String>, cx)` (selects the first match at or after the caret), `Editor::find_step(&mut self, forward: bool, cx)`, `Editor::replace_current(&mut self, replacement: &str, cx)`, `Editor::replace_all(&mut self, replacement: &str, cx)`, `Editor::find_status(&self) -> Option<(Option<usize>, usize)>` (current index, count).

- Matches recompute in `refresh` while a query is set; lines paint matches in `theme.found` beneath the selection; the current match is selected and revealed.
- `replace_current`: if the selection is exactly a match, replace it (one undo step) and select the next; otherwise just select the next match.
- [ ] UI tests: searching selects the first match after the caret; next and previous wrap; typing a new match updates the count; replace when the selection is not a match only moves; replace all is one undo step.
- [ ] Commit `feat(editor): find, highlight and replace`.

### Task 3: The find bar

**Files:** Create `crates/focal/src/find_bar.rs`; modify `workspace.rs`, `menus.rs`, `main.rs`, `ui_tests.rs`.

- `FindBar` entity: a find input, a replace input (shown with ⌥⌘F), "3 of 12" or "No matches", buttons Previous/Next/Replace/All (with tooltips naming shortcuts). Emits `Query(String)`, `Step(bool)`, `Replace(String)`, `ReplaceAll(String)`, `Dismiss`.
- Workspace: `Find` (⌘F) opens the bar seeded with the selected text (single line) or the last query, focused and selected; `FindAndReplace` (⌥⌘F) also shows the replace field; `FindNext`/`FindPrevious` (⌘G/⇧⌘G) work with or without the bar; Return/⇧Return in the find input step; Return in the replace input replaces; Escape closes and returns focus to the editor with the match selected. Opening another file in folder mode keeps the query for the new editor.
- Menu: Edit ▸ Find ▸ Find…, Find and Replace…, Find Next, Find Previous.
- [ ] UI tests: ⌘F, type, Return selects the second match; Escape closes and focuses the editor; ⌥⌘F replace all through the bar.
- [ ] Commit `feat(find): a find and replace bar`.

### Task 4: New, Open… and Open Recent, without losing untitled text

**Files:** Create `crates/focal/src/recent.rs`; modify `windows.rs`, `menus.rs`, `main.rs`, `editor.rs`, `mac.rs`, `ui_tests.rs`.

- `NewWindow` (⌘N) opens an untitled window; `OpenFiles` (⌘O) shows the open panel (files and folders, several at once) and opens each through `windows::open`.
- `recent.rs`: `Recent { paths: Vec<PathBuf> }` in `~/Library/Application Support/Focal/recent.json`; `add(path)` moves it to the front, keeps 10; `existing()` drops missing paths; `clear()`. `windows::open` records every opened path (file or folder), calls `cx.add_recent_document`, and rebuilds the menus. File ▸ Open Recent lists file names (folders end in `/`), then "Clear Menu".
- Untitled documents with unsaved edits: the window's close asks through `NSAlert` (Save…, Don't Save, Cancel); Save… runs the save panel and closes after saving. ⌘Q with such windows asks once ("Quit and discard N untitled documents?").
- [ ] Tests: `recent` add/dedupe/limit/missing/round trip; UI: ⌘N opens a second window; closing an edited untitled editor is refused until answered (the decision function is unit-tested; the alert itself is manual).
- [ ] Commit `feat(files): New, Open… and Open Recent`.
